# recall

과거 Claude Code 세션에서 지금 필요한 대목을 찾아, 요약을 현재 세션에 넣어 주는 mod입니다.

## 사용법

- `/recall <질문>`: 우측 pane에 관련 구간의 요약 카드가 뜹니다. 카드를 체크하고 [선택 항목 주입]을 누르면 현재 대화에 들어갑니다.
- `/recall`: 최근에 주입한 카드(최대 10개)를 다시 보여 줍니다.
- `/recall --all <질문>`: 현재 프로젝트 대신 모든 프로젝트의 최근 90일 세션을 찾습니다.

Claude가 작업 중이어도 바로 열리고, 주입도 바로 반영됩니다. 질문은 정확한 키워드가 아니어도 됩니다.

## 동작

1. **검색**: 질문을 haiku로 넓힌 검색어(동의어, 영어 표기, 에러 코드 등)로 세션 파일을 grep합니다. 그 결과와 세션 제목·사용자 프롬프트 색인을 sonnet에 넘겨 관련 세션을 최대 3개 고릅니다.
2. **구간 추출**: 고른 세션마다 sonnet이 관련 구간(연속된 턴)을 찾아 요약합니다. 세션당 입력은 5만 자까지이고, 검색어가 걸린 턴과 그 앞뒤를 우선 남깁니다.
3. **주입**: 고른 카드의 요약(결정 사항 / 바뀐 파일 / 미해결 항목)과 원본 세션 파일 경로를 `$.session.append`로 대화에 넣습니다. 추가 턴은 생기지 않습니다. 성공하면 채팅창에 안내 한 줄을 남기고 pane을 닫습니다.

화면과 모델 입력에는 사용자와 어시스턴트 텍스트만 쓰고, 도구 결과·thinking·서브에이전트 기록은 뺍니다.

## 비용

검색 한 번에 haiku 1회, sonnet 최대 4회(순위 1 + 구간 추출 3)를 호출합니다. 같은 세션을 같은 질문으로 다시 찾으면 저장해 둔 결과를 씁니다.

## 설치

```
/plugin install recall@junyeong-claude-code-plugins
```

mod(함수 훅) 기능이 있는 Claude Code 2.1.288 이상과 `grep`, `sh`가 필요합니다. mod API는 early access라 릴리스마다 바뀔 수 있습니다.

## 테스트

```
claude plugin test plugins/recall
```
